Project 1: My First Website

Project Name My First Website
Overview This was my first website project. I used an eye-catching design and an engaging tagline to encourage visitors to explore the site. The page serves as the main entry point to the entire website.
I created a stylesheet and designed the header, sidebar, and footer.
Technologies Used
  • HTML5
  • CSS3
  • External Stylesheet (style.css)
  • Navigation Menu
  • Responsive Layout
Reflection Creating my first website was a valuable learning experience because I had to experiment and solve problems throughout the process. I spent a great deal of time creating the stylesheet and developing the overall design. Even adding a single photograph required repeated adjustments to its size and its balance with the rest of the page. I repeatedly arranged several images and checked how they appeared. Although the process took a long time, I learned a lot from the experience.

Project 2: About Me

Project Name About Me
Overview This page introduces me. I used photographs and lists to present information about myself in a clear and accessible way. I also added interactive elements that allow visitors to access other pages.
Technologies Used
  • HTML5
  • CSS3
  • CSS Grid Layout
  • Image Integration
  • Hyperlinks
Self-Evaluation It was difficult to achieve a good balance between the photographs and the text. Although I was not completely satisfied with the result, I managed to create a page that was presentable. Small changes to the CSS sometimes disrupted the overall layout. My understanding of where to place specific code in the HTML was still limited, and some elements extended beyond the main content area, causing the design to look incorrect. I had to make repeated adjustments to correct these problems.

Project 4: My Travel Experiences

Project Name My Travel Experiences
Overview This project presents the countries I have visited, using a grid layout to display photographs of each destination.
Technologies Used
  • HTML5
  • CSS3
  • CSS Grid Layout
  • Image Gallery
  • Responsive Design
Self-Evaluation I focused especially on using CSS Grid to arrange the photographs. I learned how to upload and manage a large number of photographs. I tried compressing them all at once, but that was not enough, so I checked each photograph individually to make sure its file size was below 300 KB. Since there were so many photographs, I also learned to organize them into folders and label the photographs according to their folder names. I also learned how to design grid cards.

Project 5: Johannes Knudsen

Project Name Johannes Knudsen
Overview I created this project to help more people learn about the story of Johannes Knudsen, which connects Denmark with my hometown.
Technologies Used
  • HTML5
  • CSS3
  • CSS Grid Layout
  • Image Cards
  • Responsive Design
  • External Stylesheet
Self-Evaluation I initially thought I could create this project simply by adapting my About Me page. However, when I tried to change the photograph sizes, the images became much larger than expected, and correcting this took a considerable amount of time. I experimented with different layouts and tried to adjust the overall balance without affecting the About Me page. Whenever I attempted something more complicated, I sometimes lost the balance of the design and had to rebuild parts of the page. Although I had many ideas, turning them into the design I wanted was difficult. I repeatedly fixed one problem only to find myself returning to an earlier version.
